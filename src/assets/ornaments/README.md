# Ancient Celestial UI SVG Asset Pack

Designed to complement the supplied dark navy / gold birth-certificate UI while making it feel older, ritualistic and astronomical rather than changing its core visual identity.

All assets:
- are true vector SVG
- have transparent backgrounds
- contain no text
- use `currentColor`, so CSS can recolor them directly
- are intentionally restrained enough for UI use

Suggested CSS:
`color: #F2C84B;`
For secondary linework:
`color: #7C83A8; opacity: .55;`

Best placements:
- celestial_corner_ornament: certificate/card corners
- celestial_arch_frame: Furby portrait frame
- lunar_phases_row: section divider or natal-chart header
- orbital_halo: behind zodiac/planet glyphs
- constellation_cluster / starfield_sprinkle: low-opacity background texture
- temple_divider / ancient_bracket: section separators
- meander_border: subtle ancient geometric edge detail
- celestial_rosette / wax_seal_star: seal and provenance elements
- card_side_sigils: narrow vertical ornamental strips
